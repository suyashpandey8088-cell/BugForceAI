# Security
Untrusted code is parsed, never executed; linters run via argv (no shell) in temp dirs with timeouts and output caps. Binary/oversized inputs rejected. Per-user authorization on every review query (404 for others' data). CORS allowlist from env. Secrets only in env vars; redacted from errors. LLM: repo content is data, not instructions (system prompt enforces); output schema-validated; line numbers checked against source; patches never auto-applied. Rate limiting via slowapi. Future dynamic execution would require a disposable sandbox — not implemented, not claimed.
